# Простой генератор словарей

## ⚙ Что умеет:
- ✅ Добавлять годы (2025, 2026...)
- ✅ Менять регистр (admin, Admin, ADMIN)
- ✅ Leet-замены
- ✅ Добавлять префиксы/суффиксы (admin123, !admin)
- ✅ Удалять дубликаты


## 🔅 Как запустить

```cmd
python generator.py admin,user,root...
```

## 💬 Пример вывода программы
```text
-----------------------------------
ГЕНЕРАТОР СЛОВАРЕЙ v1.0
-----------------------------------

1: Ввести слова вручную
Введите слова через запятую (например: admin,user,root): alex,user,root

2: Загрузить из файла (каждое слово на новой строке)
Путь к файлу (оставьте пустым если не нужно): 

Имя выходного файла (по умолчанию wordlist.txt): 

Генерация словаря из 3 слов...

[!] ГОТОВО!
   Сгенерировано слов: 93
   Сохранено в файл: wordlist.txt
```
